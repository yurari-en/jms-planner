- JMS用語: オプションは公式では「追加オプション」、ファンは「追加能力」「転生」「フレーム」とも呼ぶ。装備アイコン左上「〇」=追加オプションなしで取得、「●」=取得時から付与(JMS公式 装備強化)。
- KMS公式: 名前に「카르마」「대적자」を含んでも確率は同一。
- JMS公式: 交換可能装備に転生の炎を使うと装着時に交換不可が付く(カルマのはさみ使用可能装備は除く)。

### 1.2 入手方法(JMS)
- 強力な転生の炎: ユニオンコインショップ、エリートモンスター、ポロとプリトの賞金稼ぎ、デイリーギフト、モンスターコレクション探検、モンスターパーク火曜日箱、一部ボス、イベント、オークション(wikiwiki mapleinm / JMS公式装備強化)。
- 永遠の転生の炎: ユニオンコインショップ、イベント、ハードボス、オークション、専門技術制作(転生の欠片+消えない炎)。
- 深淵: イベント・パス報酬(例: チャレンジャーズワールドS3 ジェネシスパス)。
- KMS参考(2026-03-19): 유니온 코인샵(타오르는/카르마 타오르는)、몬스터 컬렉션 탐험(타오르는/검은)、몬스터파크 화/토 상자(타오르는/검은)、무릉 포인트샵(타오르는)。namu: 以後ボス報酬からの定常入手は(デイリーギフト除き)削除。

### 1.3 メル(メソ)で回す仕組み
- **KMS [公式, 2026-03-19, client 1.2.413]**: 「추가옵션 재설정 시스템」— 통합 강화 UI から、**1回 3,000,000 메소(固定、Lv依存の記載なし)**、確率は검은 환생의 불꽃と同一、旧/新選択可。自動再設定(目標達成で停止、目標は6段階まで指定可、「전투력 상승 시 중단」オプション)。
- **GMS**: v.271(2026-09)でメソリセット導入、KMS黒炎と同確率(ottojaa flames.py の docstring による。GMS公式本文は未取得)。
- **JMS**: CROWN(2026夏)で「追加能力を統合UIから自動で引き直し、転生は前後選択、メルでも回せる」予告(kawaii-sushi CROWNまとめ)。2026-09-16のver4.45で自動再設定に使えるのは5種(強力/永遠/黒い/深淵/メル再設定)と整理(kawaii-sushi)。JMS公式本文(CROWN その1 項目9「追加オプションシステムの改変」, ver4.45)はページ変換の都合で本文取得できず。**JMSのメル費用・メル再設定の確率は未確定(KMSと同じ 300万メル・黒い炎相当と仮定するのが妥当)**。
- 自動再設定の目標上限(JMS, kawaii-sushi): 強力=一般4/ボス6、永遠・黒い・深淵=一般5/ボス7。→ 強力ではボス装備でもtier7は出ない(KMS公式 強力 5段階 0% と整合)。

### 1.4 1個あたりコスト換算の手がかり
- メル再設定: KMS 3,000,000メソ/回(公式)。JMSも同額仮定(未確定)→ ツールではユーザー入力可能にする。
- 炎アイテム: 取引可能な非カルマ版はオークション相場、ユニオンコイン/ポイント系は「コイン単価×交換レート」で換算。**JMSのユニオンコインショップ価格は未確認**(入力パラメータ化)。
- 新旧選択できる手段(黒い/深淵/メル再設定)は「最良値を保持して回し続ける」モデル、選択不可(強力/永遠)は「毎回上書き」モデルで期待値が変わる(§6.4)。

## 2. 抽選ルール

### 2.1 行数 [KMS公式]
| 取得方法 | 1行 | 2行 | 3行 | 4行 |
|---|---|---|---|---|
| **ボス装備(flame advantage)** | – | – | – | **100%** |
| 환생의 불꽃류(炎・メソ再設定, 非ボス) | 40% | 40% | 16% | 4% |
| 장인 제작 | 21% | 50% | 25% | 4% |
| 명장 제작 | 0% | 56% | 40% | 4% |
| その他(ドロップ等) | 41% | 40% | 15% | 4% |

- JMSファンwiki(mapleinm)は「1行45/2行35/3行15/4行5%」と記載 → KMS公式と不一致、出典なし。**KMS公式値を採用、JMS値は未確定**。
- JMS公式の強力な転生の炎説明文は「追加オプションを4個付与および再設定」だが、これはボス装備前提の文言と思われ、非ボス装備で常に4行かは **未確定**(KMS公式では非ボス 40/40/16/4)。

### 2.2 オプション種類の抽選 [KMS公式]
- 各部位19種から **重複なし・均等確率** で行数分を選ぶ(2021-02-19から균등)。
- 各行の段階は **行ごとに独立** に抽選。
- 「再設定結果が既存と完全同一ならもう一度再設定」(KMS公式。実用上は影響無視可)。
- レベル制限で候補から外れる種類は候補数が減る(均等のまま残り候補で抽選、と解釈。**除外時の扱いは推定**)。

### 2.3 段階(tier)確率 [KMS公式] — 1〜5段階表記、ボス装備は **+2段階**(3〜7段階)
| 方法 | 1 | 2 | 3 | 4 | 5 | ボス装備換算 |
|---|---|---|---|---|---|---|
| モンスタードロップ | 25 | 30 | 30 | 14 | 1 | 3〜7 |
| 強力 / 타오르는 | 20 | 30 | 36 | 14 | 0 | **3〜6** (20/30/36/14) |
| 永遠 / 黒い / メソ再設定 | 0 | 29 | 45 | 25 | 1 | **4〜7** (29/45/25/1) |
| 深淵 | 0 | 0 | 63 | 34 | 3 | **5〜7** (63/34/3) |
| 一般合成/制作 | 50 | 40 | 10 | 0 | 0 | |
| 장인 제작 | 15 | 30 | 40 | 14 | 1 | |
| 명장 제작 | 0 | 19 | 50 | 30 | 1 | |
| 장인 합성 | 25 | 35 | 30 | 10 | 0 | |
| 명장 합성 | 0 | 40 | 45 | 14 | 1 | |
| 장비 각인 찬스타임 | 0 | 30 | 50 | 19 | 1 | |

- 依頼文の「強力: 3〜6段階 20/30/36/14%、永遠: 4〜7段階 29/45/25/1%」は **ボス装備の場合として正しい**(KMS公式で確認)。
- JMSファンwiki(mapleinm)は強力を 25/30/30/14/1(=ドロップ分布)と記載 → JMS自動再設定の目標上限(強力ボス6)と矛盾するため **誤りの可能性が高い**。
- 固定段階アイテム [KMS公式]: 1段階固定(내 머리속의 외계인, 쯔바이핸더, 크리스탈 크러셔 等)、2段階固定(메이플 레이서 시리즈 等)、3段階固定(約200品: 메이플 트레져, 블랙, 프로스티 等)、4段階固定(레베카 一部)。 → 計算対象外(炎で再設定すれば通常ルール)。

### 2.4 ボス装備 / 非ボス装備
- ボス装備: 4行固定・+2段階。例: ルートアビス(カオス)防具・武器、アブソラブス、アーケインシェード、エテルネル、ボス装飾品(ペンダント/顔/目/耳/ベルト/ポケット 等)、マイスター、ジェネシス武器、ネクロ/ロイヤルヴァンレオン/女帝 (namu脚注, whackybeanz)。
- **非ボス扱いの例外**: (カオス)ホーンテイルネックレス、永生の石、カオスルートアビス帽子(1〜5段階)、ゼロ武器(whackybeanz)、JMS: スイングウォーター・ヴェラッド装備は「ボス装備ではない」(JMS公式)。
- エリートボスドロップ品(GMS): 取得時のみ高段階、炎使用後は通常ルール(StrategyWiki)。

### 2.5 黒い炎・深淵・メル再設定の「旧オプション保持」
- 使用後、**再設定前(旧)と再設定後(新)のどちらを適用するか選択**(KMS公式パッチ、JMS kawaii-sushi「適用有無を決めることができる」)。
- namu: 검은 불꽃は「가위 횟수 없는 아이템에도 가위 횟수 적용」等の付随仕様あり(取引系、計算には無関係)。

## 4. 数値式(段階 s、装備Lv L = 着用レベル減少前の元Lv)

| オプション | 式 | 出典/備考 |
|---|---|---|
| 単一ステ | `(floor(L'/20)+1) × s`、L' = (L≥250 ? 220 : L) | namu(250→220の脚注)。StrategyWiki: 200-229=11, 230+=12 と整合 |
| 複合ステ(各ステに) | `(floor(L/40)+1) × s` | namu, StrategyWiki(250+=7) |
| 最大HP/MP | `floor(L/10)×10 × 3 × s` | namu(一の位切捨て)。エテルネル防具は L=233.33扱い→ **700×s** |
| ⚠HP 200-249 | StrategyWiki: 200=600, 以後10Lvごと+20(240-249=680), 250+=700 / namu式: 210→630 | **未確定(210〜240台装備で差)**。200と250は両式一致 |
| 防御力 | `(floor(L/20)+1) × s` | StrategyWiki/Xenogents(single stat表と同じ)。namu記載なし。実害なしのためスコア0 |
| 攻撃力/魔力(武器以外) | `s` | KMS/GMS一致。Lv60未満は候補外 |
| 移動速度/ジャンプ | `s` | StrategyWiki |
| オールステータス% | `s` % | |
| ボスダメ%(武器) | `2 × s` % | |
| ダメージ%(武器) | `s` % | |
| 着用Lv減少 | `−5 × s` | 強化費用等は元Lvのまま |
| **攻撃力/魔力(武器, ボス武器)** | `ceil( B × (floor(L/40)+1) × s × 1.1^(s−3) / 100 )` | namu式。B=基本攻撃力(魔力は基本魔力、無ければ基本攻撃力) |
| 攻撃力/魔力(武器, 非ボス武器) | `ceil( B × (floor(L/40)+1) × s × 1.1^(min(s,5)−1) / 100 )` | StrategyWiki(GMS)。KMS公式出典なし **未確定** |
| ゼロ武器 | 非ボス式、ラピス基準。特殊%(ボス/ダメ/AS)は効果2倍(表示は同じ) | StrategyWiki |
| Lv250武器(デスティニー) | ボス式で floor(250/40)+1=7 になるか、StrategyWiki表「200+=6%」か | **未確定**(実測表見つからず) |

### 4.1 武器攻撃力式の検算(全て一致)
| 武器 | L | B | 計算 tier3/4/5/6/7 | 実測(出典) |
|---|---|---|---|---|
| ジェネシス(片手剣) | 200 | 326 | 59/87/119/157/201 | namu 59/87/119/157/201 |
| ジェネシス(銃) | 200 | 249 | 45/66/91/120/154 | kawaii-sushi 同値 |
| アブソラブス銃 | 160 | 150 | 23/**33**/46/60/77 | kawaii-sushi 同値 |
| ファフニール | 150 | 86 | 11/16/21/28/36 | namu/StrategyWiki 同値 |
| namu例 | 200 | 200 | tier6 → 96 | namu 96 |

- **丸めは ceil(切り上げ)**。Xenogents実装の `floor(x)+1` は x が整数のとき1大きくなる(例: アブソ銃 150×22% = 33.0 → 34 になってしまう)→ **不採用**。
- 浮動小数点で `150*0.22` が 33.000000000000004 になる等の誤差で ceil がずれるため、**有理数(分子分母整数)で計算**すること: `ceil(B × k × s × 11^(e) / (10^e × 100))`。

## 5. 追加オプション可否

- **付かない** [KMS公式]: 盾(방패)・補助武器・肩装飾・指輪・勲章。
  [JMS公式/JMSファン] 追加で: エンブレム、バッジ、アンドロイド・機械心臓、称号、補助武器(ブレイド=デュアルブレイドの刃 含む)。例外として **スカーレットショルダー**、**シークレットリング**(JMS公式の記載。付く側の例外として扱う)。GMS: トーテム(古代の石板レプリカ除く)不可。

### 6.3 「今より良い」判定
- 防具: `score(new) > score(current)`(同点を含めるかは設定)。
- 武器: 一般に辞書式(攻撃力段階 → ボス% → ダメ% → AS%)または線形スコア(攻撃力1 = 主ステ換算ではなく、ダメージ寄与で係数化)。ツールでは「目標条件(各オプション最低段階)」モードと「スコア閾値」モードを両方提供。

### 6.4 期待試行回数・コスト
- 1回の成功確率 p = P(score ≥ T)。試行回数は幾何分布: 期待 1/p、N回以内成功 1−(1−p)^N、中央値 ceil(ln0.5/ln(1−p))。
- 新旧選択可(黒/深淵/メル): 現在値を床にして最良保持。N回後の期待最良 E[max(cur, X1..XN)] = Σ_x max(x,cur)·(F(x)^N − F(x⁻)^N)。
- 選択不可(強力/永遠): 「T以上が出たら止める」以外は上書きされるため、停止ルール付きで評価(目標到達確率は同じ p、ただし途中で現在値を失う)。

### 7.3 数値関数(有理数で)
```ts
single(L)  = floor((L>=250?220:L)/20)+1
double(L)  = floor(L/40)+1
hp(L,s)    = floor(L/10)*10*3*s            // エテルネル(250)は 700*s。200-249は未確定
watt(B,L,s,boss): e = boss ? s-3 : min(s,5)-1
                  num = B*(floor(L/40)+1)*s*11^e ; den = 100*10^e   // e<0 は来ない(ボスはs>=3)
                  return ceilDiv(num, den)                          // BigInt整数演算
lineValue(opt,s,eq): STR..=single*s / 複合=double*s(両ステ) / ATT,MATT = weapon? watt : s
                     BOSS_DMG=2s, DMG=s, ALL_STAT_P=s, REQ_LV=5s, SPEED/JUMP=s, DEF=single*s
lineScore(opt,s,eq,w) = Σ_k w[k]*lineValue[k]   (ゼロ武器は特殊%×2)
```

### 7.4 厳密分布: 動的計画(推奨)
重複なし均等選択 × 行ごと独立段階 → 「どの n 個の組合せも等確率 1/C(P,n)」を利用。
スコアに寄与するオプション集合 R(|R|=r)、寄与ゼロのオプション数 z=P−r。
```
// d_o : オプション o の1行スコア分布 {score: prob}(段階分布から)
dp[0] = {0:1}; dp[k] = {}         // dp[k]: R から k 個選んだ“全組合せの和”(確率重みは段階のみ)
for o in R:
  for k = min(4,r)-1 downto 0:
    for (a,pa) in dp[k], (b,pb) in d_o: dp[k+1][a+b] += pa*pb
result = {}
for (n,q) in lineProb:            // ボス: {4:1}
  for k in 0..min(n,r):
    ways = C(z, n-k); if ways==0 continue
    for (s,w) in dp[k]: result[s] += q * w * ways / C(P,n)
```
- 計算量: r≤19, 各 d_o は≤5点、スコア種類は数千程度 → ブラウザで数ms。
- スコアは浮動小数で集計キーが割れるので、係数を整数化(例: 全係数×8)するか round(x,6) をキーにする。
- 多次元条件(「攻撃力≥X かつ ボス≥Y」)は、スコアの代わりに **状態ベクトル(各条件の達成フラグ or 上限で打ち切った値)** を dp のキーにする。武器の典型ケースは閉形式: `P = C(P−m, 4−m)/C(P,4) × Π P(tier_i ≥ t_i)`(m = 条件を課すオプション数、ボス4行時)。非ボスは n 行ごとに `C(P−m, n−m)/C(P,n)` を行数確率で加重。
- 検証: 全列挙(C(19,4)=3876 × 段階^4 ≤ 625 ≈ 242万通り)でテストし DP と一致すること(本調査で Lv200/永遠 で一致確認済み)。
